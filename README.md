# 📊 E-Commerce Data Analysis
## 📌 Project Overview

This repository contains an Exploratory Data Analysis (EDA) of a [public E-Commerce dataset](https://drive.google.com/file/d/1MsAjPM7oKtVfJL_wRp1qmCajtSG1mdcK/view). The dataset includes multiple tables containing information about customers, orders, payments, products, and sellers. The goal of this analysis is to uncover trends and insights from the data.

## 📂 Dataset Details
The dataset consists of 6 tables:
- **Customer** Table: Information about customers
- **Order** Table: Details of customer orders
- **Payment** Order Table: Payment transaction data
- **Review** Order Table: Customer ratings
- **Product** Table: Information about products
- **Seller** Table: Details of sellers

## 🔍 Analysis Process
- **Data Wrangling**: Performed using Jupyter Notebook for data loading and preprocessing.
- **Data Cleaning**: Handling missing values, duplicate data, and structural inconsistencies.
- **EDA (Exploratory Data Analysis)**: Merging tables to derive meaningful insights.
- **Data Visualization**: Implementing visualizations using Streamlit for an interactive dashboard.
